# Retail Management System (C# WinForms)

## Introduction
A desktop application designed for managing retail operations including products, employees, customers, and invoices.

## Tech Stack

Language: C#

Framework: .NET Framework (WinForms)

Database: MS SQL Server

## Key Features

User authentication (Login system).

Inventory management (CRUD operations for products).

Employee and Customer records management.

Invoice generation and sales tracking.
